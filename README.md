## 项目介绍
本项目是前后端分离架构的智慧社区后台管理系统，分为平台管理员、商家租户两套独立管理端，采用多租户数据隔离方案，集成AI大模型与RAG检索能力，配套社区服务订单、邻里社交、在线客服等基础业务，用于管理社区便民上门服务，实现平台统一监管、商家独立运营。

## 系统功能
### 一、平台管理员端（全局管控）
1. 系统管理：平台账号、角色权限、动态菜单配置、租户管理
2. 资讯管理：社区资讯发布管理
3. 服务管理：服务分类维护、服务审核
4. 邻里圈管理：社区话题标签管理、帖子审核
5. AI助手管理：RAG知识库上传维护、AI问答
6. 反馈管理：用户意见反馈

### 二、商家租户端（店铺自营）
1. 服务管理：自有服务增删上下架、上门服务人员管理、服务评价
2. 订单管理：订单接单/拒单、指派人员、处理退款取消申请
3. AI助手管理：RAG知识库上传维护、AI问答
4. 客服管理：WebSocket实时聊天
5. 财务管理：收益数据
